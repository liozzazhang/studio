# Studio 改版验证

核对日期：2026-11-19（内容模块化、履历校准与简历下载）。

## 内容与结构

- 面向读者的文案全部位于 `content/`：界面文案在 `ui.json`，履历在 `profile.json`，简历在 `downloads/`，项目在 `projects/`、`lab/`、`wow/`。构建器与前端脚本只保留中英切换按钮本身的标签。
- 首页按 `ui.json` `home_sections` 渲染：关键成果、我的工作、职业履历（含 Cisco 三阶段的项目、指标与相关作品）、工程演进、代表作品、简历下载、工作之外、联系我。
- 履历以 AI 简历为主线，技术简历补充实现细节，管理简历补充团队与交付；项目代号与成果数字已公开，内部链接、源码、拓扑与凭证不公开。
- 简历下载：AI、技术、管理与 AI 项目经历四组，每组中英文 × PDF / Word，共 16 个文件。PDF 由 Word 导出，已去除导出时自动加盖的敏感度标签页脚并重置元数据。
- 38 个独立项目模块：30 个公开、8 个私有；`dns-eyes` 已改为说明工作版本交付与个人仓库现状。

## 自动检查

- `python3 scripts/build_catalog.py --check`：70 个产物与内容一致。
- `check_public_catalog.py --gh`：30 个公开仓库在线可见，8 个私有摘要声明通过。
- 隔离副本中验证：删除下载组后清理旧文件；格式与文件头不符、路径穿越被拒绝；缺少 `ui.json` 键直接报错；从 `home_sections` 移除分节后节号重排。
- 52 个 HTML 页面、975 条内部引用与锚点无断链；16 个下载地址均返回 200 且类型正确。

## 浏览器核对

- 桌面：首页各分节、职业履历项目与相关作品、简历下载卡片、联系方式。
- 手机（390px）：无横向溢出；概览改为两列，下载卡片单列。
- 默认英文：首次访问及无 JavaScript 时为英文（`default_language: en`）；首页、项目目录、详情、权限申请页与 404 除切换按钮外无中文残留；切换中文后记住选择，目录计数与搜索提示同步切换。
