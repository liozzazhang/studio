## 申请访问与维护边界

网站为私有项目提供弹窗和独立申请页，说明通过邮件提交 GitHub 用户名、希望查看的项目及用途。邮件链接只打开客户端，不自动发送、不自动授权。站主根据可分享范围回复，实际访问权限由 GitHub 管理。

构建前检查会验证所有显式声明为公开的仓库仍可公开访问，并校验私有摘要的声明；不会下载私有源码。浏览器不持有 GitHub 凭据，也不实时请求仓库接口。

`site/` 之外的资料不进入 Pages 产物，但仍属于公开 Studio 仓库。内容模块、Markdown、文档与模板均应按公开资料维护；原始履历、聊天导出、内部文档、接口原始响应和凭据不提交。
