## 维护方式

每个项目目录包含必需的 `project.json` 与可选的 `README.zh.md`、`README.en.md`。新增或删除项目目录后，构建器自动生成总目录、分组目录和详情页，不必编辑中心列表或模板中的项目名称。

项目详细介绍、标签与来源链接以对应模块为准；私有项目必须保留 `disclosure: summary-only`，所有提交到 Studio 的模块内容本身都是公开资料。设计、原型、初始化和归档状态不视为已部署或已验证运行。
